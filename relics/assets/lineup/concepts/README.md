# Generated badge art concepts

The gallery contains 80 generated images across 34 Sidelines badges. That includes two prompt-aligned concepts per badge plus earlier generated explorations for Ball, Clap, Fire, From Corner, and Volley.

The PNGs and the generated soccer-field background are for design review. The original SVG files in the parent folder remain the active lineup icons. Nothing in this folder replaces or changes how the app selects its icons.

Open `index.html` to browse the responsive image gallery. The revised generation prompts are in `sidelines-badge-art-prompts.md`.
