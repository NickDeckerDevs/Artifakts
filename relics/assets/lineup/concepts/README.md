# Generated badge art concepts

This folder contains AI-generated concept options for the 34 Sidelines lineup badges: one option that builds on each existing badge and one alternative direction. Browse the paired gallery in `index.html`; the revised generation prompts are in `sidelines-badge-art-prompts.md`.

These 68 PNGs are design explorations, not app assets. The original SVG files in the parent folder remain the active lineup icons. Nothing here replaces or changes how the app selects its icons.
