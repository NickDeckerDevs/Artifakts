THE RACK / LOCAL BUILD KIT

Connections first. Then the build.

Ethernet, wall plates, power sockets, labels and installation records in one offline kit.

P means Proposed. Every required connection has a build target. Existing evidence remains separate from the proposal. Publishing this plan does not mean any cable has been moved or every live connection verified.

1 · While the network is still working

  • Download the ZIP, extract the whole folder and open START-HERE.html on the laptop. Keep the files together.
  • Open the Ethernet map and Power + USB map from the extracted folder.
  • Label each existing cable at both ends before unplugging it.
  • Match the four existing office leads to PC, Mac Studio, Apple TV and Samsung TV. The current NEAR/FAR plate-to-device positions are not recorded; WP01 jack numbers in the map are proposed.
  • Match the two right-hand jacks on the existing family-room plate to Family room BACK and NVR. Keep the unknown cable labeled separately.
  • Lay each proposed jumper alongside its complete route. Use a longer cable wherever the 0.2 m jumper cannot reach with slack.
  • Record the current router LAN address, DHCP range and switch management address in the saved connection notes. Confirm the new gateway settings before a fiber switch-over; these settings have not been verified in this build record.
  • Review the power feed shown in Power + USB. This plan retains the existing guide’s separate wall feed for the PDU; the PDU loads are not battery backed on that feed.

Resolve the items above before disconnecting the working network. The garage can stay deferred. Do not guess an existing cable identity from its proposed jack number.

2 · Run the new room cables

The two existing four-jack plates stay in the map. The six empty openings each take a four-jack plate; only needed jacks are populated.

  • WP03 · top-left empty opening: Guest bedroom · jacks 1 and 2. Run and label GUEST-1 and GUEST-2.
  • WP04 · top-middle empty opening: Child bedroom · jacks 1 and 2. Run and label BED-2 and BED-2B.
  • WP05 · top-right empty opening: Master bedroom · jacks 1 and 2. Run and label MASTER-1 and MASTER-2.
  • Terminate each new run at its rack-side wall-plate jack and matching room-side wall-plate jack.
  • Test and label each run before relying on it.
  • WP06 · bottom-left: garage jack 1 is proposed. Test the unknown existing cable first; reuse or repair it if it is the garage run. Pull a new cable only if needed. Garage is last.
  • WP07 / WP08 · bottom-middle / bottom-right: leave unused. Jacks 3 and 4 on the bedroom plates are also available.

3 · Wire the rack from the map

  • Mount Expo at the right above Floor Plan. Keep Runner centered below Floor Plan.
  • Use the map’s connection ID and both-end label for one cable at a time.
  • Follow the full chain: switch socket, front jumper, Floor Plan socket, rear jumper, rack wall-plate jack, wall cable, room jack and room jumper.
  • Connect rack equipment directly to its assigned switch. NAS, SmartThings, gateway and switch uplink do not need a room wall plate.
  • Keep the NAS pair identifiable. The proposed target is upper to Expo 2 and lower to Expo 4; the existing individual upper/lower assignment was not recorded.
  • Use Power + USB to follow each supply from source socket through its original adapter to the device. Label both ends.
  • Leave unassigned PDU / UPS sockets and charging sockets empty.
  • Use the actual printed outlet-bank labels on the UPS. B1–B6 are labels you apply in the Battery/Surge bank, not factory socket numbers.

4 · Check each connection and save what you built

  • Check PC, Mac Studio, Apple TV and Samsung TV at the intended switch sockets.
  • Check the family-room switch / PlayStation branch.
  • Check the separate NVR run.
  • Check NAS access from the office.
  • Check Orbi Wi-Fi after matching its physical uplink.
  • Check SmartThings and the SONOFF USB connection.
  • For each finished connection, open “Record this connection after installation,” mark it connected/tested and record any changed socket or jack.
  • Choose “Save record” and keep the downloaded JSON with this folder. Use “Load record” to restore it on the same or another laptop.
  • If a proposed reassignment fails, restore that cable to its labeled original socket and record the discrepancy. Do not change switch settings just to match the drawing.

Materials to have ready

  • Six bedroom cable runs: two each to Guest, Child and Master bedrooms.
  • Twelve new termination jacks for those six runs: six rack-side and six room-side. Verify these separately from the patch panel’s insert count.
  • Six rack-side rear jumpers and six front jumpers for those new runs; use lengths that reach with slack.
  • Six room-side jumpers when attaching devices.
  • Garage adds one run, two termination jacks and jumpers only if the existing unknown cable cannot be reused.
  • Colored inserts, jumpers or matching label tape; labels at both ends.
  • Original power supplies. The Raspberry Pi model and matching supply are still to be identified.
